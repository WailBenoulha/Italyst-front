# 🇮🇹 Italyst

**Italyst** is a web platform designed to simplify access to Italian universities for international students. It centralizes essential information about universities, admission requirements, tuition fees, and deadlines—making the application process clearer, faster, and more accessible.

## 🚀 Features

* 📍 Browse universities by Italian regions
* 🎓 Explore Bachelor & Master programs
* 📊 View admission requirements (GPA, IELTS, alternatives like MOI)
* 💰 Check tuition fees and scholarship opportunities
* 📅 Access application deadlines and timelines
* 🔗 Direct links to official university and admission pages
* 🧠 Simplified and structured data for better decision-making

---

## 🛠️ Tech Stack

* **Frontend:** React.js
* **Data Management:** JavaScript (structured JSON dataset)
* **Styling:** CSS / Tailwind (if used)
* **Version Control:** Git & GitHub

## 🎯 هدف المشروع (Project Goal)

The goal of Italyst is to **reduce the complexity** of applying to Italian universities by:

* Making information **centralized**
* Providing **clear and realistic requirements**
* Helping students avoid confusion and missed deadlines
